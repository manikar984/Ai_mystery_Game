# AI Mystery Room

An interactive fictional detective game. Enter a premise, inspect an AI-generated (or local demo) case file, and make one final accusation. Generated investigations and all evidence are fictional; simulated camera material is always labeled.

## Requirements

- Node.js 20 or newer and npm
- MongoDB for durable case storage (optional for local demo mode)
- A Google Gemini API key for AI-generated cases (optional; demo mode runs without it)

## Run locally

1. Copy `.env.example` to `.env` and fill in `MONGODB_URI` and `GEMINI_API_KEY` when available. Leave `GEMINI_API_KEY` blank to use the built-in fictional demo case. When MongoDB is not configured or unavailable, cases are held in memory and are lost when the server restarts.
2. Install the workspace dependencies with `npm install`.
3. Start client and API together with `npm run dev`.
4. Visit `http://localhost:5173`. The API health check is `http://localhost:5000/api/v1/health`.

For a production deployment, configure durable MongoDB, a supported `GEMINI_MODEL`, a secure origin, and durable object storage for generated media. Do not expose server environment variables to the client. This MVP uses designed, synthetic placeholders rather than a configured image/video provider.

## Commands

- `npm run dev` — start Vite and Express in watch mode.
- `npm run build` — compile the server and build the client.
- `npm start` — run the compiled API server.

## API

Base path: `/api/v1`

- `GET /health` — non-sensitive health and dependency mode.
- `POST /cases` — create a mystery (`premise`, optional `settings`). Returns the public case; the solution remains server-only.
- `GET /cases/:caseId` — retrieve the public case.
- `POST /cases/:caseId/accusations` — record the one final accusation and receive the reveal. Repeats return the saved outcome.
- `GET /cases/:caseId/result` — retrieve the saved reveal after accusation.

## Implementation notes

The app uses React, Vite, TypeScript, Express, Mongoose, Zod, and the Google GenAI SDK. Gemini calls happen only in the server. The API validates case settings, checks generated IDs and key references, hides both the solution and internal clue classifications from the public case serializer, and calculates scoring deterministically. MongoDB's TTL index follows the configured retention period. Local demo cases are in-memory and are designed as fictional example content; they are not generated by Gemini.

The current MVP implements evidence cards and a synthetic CCTV presentation, but does not generate real image or video assets. Its in-memory fallback is for local development only and is not durable storage.
